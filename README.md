# Actividad 2: Interfaz gráfica con conexión a MySQL
BookMood 📚 es una aplicación de escritorio desarrollada en C# con Windows Forms y MySQL que recomienda libros según el estado de ánimo del usuario, ofreciendo una interfaz amigable e intuitiva para descubrir nuevas lecturas.

## 🎯Objetivo:
* Desarrollar una interfaz gráfica con conexión a una base de datos en MySQL.
### 🏹Objetivos específicos:
* Diseñar una interfaz gráfica amigable que facilite la interacción del usuario con la aplicación.
* Establecer una conexión entre la aplicación desarrollada en C# y la base de datos MySQL.
* Obtener y mostrar información almacenada en la base de datos mediante consultas SQL.

## 🛠️Tecnologías utilizadas
* C #
* .NET Windows Forms
* MySQL
* MySQL Connector/NET
* Visual Studio
* Canva

## 🕹️Funcionamiento
1. El usuario abre la aplicación BookMood.
2. Selecciona la emoción con la que se identifica.
3. Presiona el botón Buscar.
4. La aplicación consulta la base de datos MySQL.
5. Se muestran las recomendaciones de libros correspondientes, incluyendo su título, autor y descripción.
